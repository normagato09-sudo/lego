# LEGO Inventario

App web para organizar una colección de piezas LEGO por forma, en cajas y bolsas con código de ubicación (ej.: C2-B03 = caja 2, bolsa 3).

Hecha con Next.js (App Router), TypeScript y Tailwind CSS. Se despliega en Vercel con cada push a `main`.

## Probar en el ordenador

```bash
npm install
npm run dev
```

Y abrir http://localhost:3000
